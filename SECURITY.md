# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/gmontana/modMARL/security/advisories/new)
rather than in a public issue. You can also email
[g.montana@warwick.ac.uk](mailto:g.montana@warwick.ac.uk).

Include the affected version or commit, the steps to reproduce the problem and its
possible impact. You will receive an acknowledgement, and the fix will be credited to
you unless you prefer otherwise.

## Supported versions

Security fixes are made to the latest release.
